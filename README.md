# AI Intel Board

Unofficial tool, not affiliated with OpenAI or any model provider. A single-file local board to collect AI news headlines you find, tag them, search them, and copy a short promo list for Instagram or X.

## What it does

- Add a headline, source, link, and tag, saved only in your browser localStorage
- Search and filter your own intel list
- Link out to official sources (OpenAI News, Google AI Blog, Anthropic News, Hugging Face Blog) — links only, no scraping, no affiliation
- Copy a short top-5 list for social posts

## What it does not do

- It does not fetch news automatically, does not log in, and needs no API key
- It does not verify claims for you: always check the original source before reposting
- The sample item is fake, for demo purposes only
